# 設定とUI

## 設定の責務

- `src/settings-schema.js`: 設定キー、既定値、許容値、正規化、検証の唯一の定義元。
- `chrome.storage.local`: 新しく開くタブへ適用するデフォルト設定。
- `chrome.storage.session`: 現在のタブで上書きした実セッション設定。
- ポップアップ: デフォルト設定を編集する。
- プレイヤー内メニュー: 現在のタブ設定を編集し、上書き値へ「タブ」表示を付ける。

設定を追加するときはスキーマ、backgroundのメッセージ処理、両UI、テストを一緒に確認する。
未知のキーは無視してよいが、既知キーの不正値は保存しない。
同一タブの更新は直列化し、異なるタブを相互に待たせない。

## プレイヤーUI

- YouTubeの標準クラスとDOM構造へ合わせる。
- 設定メニューはプレイヤーのポップアップ領域内に置き、標準の自動非表示挙動へ従わせる。
- サブメニューは`ytp-panel-header`、既存のback button、`menuitemradio`を使う。
- 戻るアイコンや選択チェックを独自に重複描画しない。
- 専用ボタンは右コントロール群の左側へ置き、全画面ボタンを押しのけない。
